# CADodiles: Raspberry Pi STEM Trivia Game

An interactive, touchscreen-based Grade 5 math trivia game built on a Raspberry Pi Zero 2 WH, pairing a Kivy graphical interface with GPIO-driven physical feedback.

---

## Project Overview

CADodiles is a classroom trivia game that makes 5th grade math review feel like an arcade cabinet rather than a worksheet. Students pick a chapter and answer questions on a 7" touchscreen; a correct answer triggers green LED flashes, a rising buzzer tone, and a servo-driven dispenser that releases a physical game piece. The project covers the full engineering design cycle — SolidWorks enclosure design, embedded hardware integration, and a complete Python application.

### Project Members
- Skyler Wang: [wang.sk@northeastern.edu](mailto:wang.sk@northeastern.edu)

### Key Features
- Touchscreen interface built with Python and Kivy
- Singleplayer and up to 4-player multiplayer modes
- Chapter selection mapped to the five Common Core Grade 5 math domains
- Three-channel physical feedback: LED strip, buzzer, and servo dispenser
- Full English / Spanish bilingual interface
- Custom SolidWorks-designed enclosure and play board
- Stub mode for development without hardware attached
